AI VIDEO STUDIO V1.0

Aplikasi PWA untuk menyusun prompt video AI, menyimpan proyek secara lokal, dan mencadangkan data JSON.

PUBLIKASI GITHUB PAGES
1. Buka Settings pada repository.
2. Pilih Pages.
3. Pada Build and deployment, pilih Deploy from a branch.
4. Branch: main, folder: /(root), lalu Save.
5. Tunggu proses publikasi selesai. Alamat: https://madeadja2026-sys.github.io/ai-video-studio/

INSTALASI ANDROID
Buka alamat aplikasi di Chrome Android, tekan menu ⋮, lalu pilih Install app atau Add to Home screen.

CATATAN
Data proyek disimpan di browser/perangkat yang digunakan. Ekspor cadangan JSON secara berkala. Aplikasi ini menyusun prompt; proses pembuatan video dilakukan di layanan AI eksternal.
